Brother DCP-T220 for Mac

Print from Word, Excel, Preview and other Mac apps using the standard print dialog.

Community driver • Version 1.0.0 • GPL-2.0

Before you begin

Connect your DCP-T220 by USB and turn it on for automatic setup. You can also install now and add the printer later.

Tested printing on macOS 27.0.1 with Apple Silicon. Other Mac versions and Intel hardware are not validated. This is not an iPhone/iPad or Windows driver.

Independent software based on zama-tui/brother-pwg-macos. Not affiliated with or supported by Brother.
