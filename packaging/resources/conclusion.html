Driver installed

Open a document, press Command-P, and select Brother DCP-T220 PWG / Brother_PWG.

If the printer is not listed

Connect it by USB. Open System Settings → Printers & Scanners → Add Printer. Select DCP-T220. Under Use, choose Select Software and search for Brother DCP-T220 PWG. If needed, choose Other and select /Library/Printers/BrotherPWG/brother-pwg.ppd.

Print quality

Under Printer Features → Print Quality: EcoMode (Draft) = 300 dpi; Normal = 600 dpi; Fine (Best) = 600 dpi with HIGH rendering. Photo at 1200 dpi is also available. Draft is not a verified equivalent of Brother's proprietary economy mode.

Please verify a one-page print before a large job. No page has been printed automatically. Your existing default printer is preserved.
