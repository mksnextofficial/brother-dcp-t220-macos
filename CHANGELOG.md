# Changelog

## 1.0.0 — 2026-10-26

- First community distribution with a graphical macOS Installer package and DMG.
- Supports installing without the printer connected; installs a discoverable model PPD for later setup.
- Automatically configures a connected USB DCP-T220, preserving unrelated queues and existing defaults.
- Names quality choices EcoMode (Draft), Normal, Fine (Best), Photo without changing protocol values.
- Preserves upstream GPL-2.0 driver, credits and history.
- Basic physical printing confirmed on DCP-T220 and macOS 27.0.1 Apple Silicon.
- Unsigned and not notarized; Intel, earlier/future OS releases, advanced quality/borderless output remain unqualified.
